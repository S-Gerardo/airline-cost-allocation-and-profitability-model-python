# Airline Cost Allocation and Profitability Model
This is a Python command line based model that breaks down airline cost allocation by cabin and profitability. Allocates direct and indirect operational cost allocation to each cabin/passenger.

# Features
- Input of passenger data and ticket revenue
- Allocates direct and indirect costs for each cabin and passenger through cost drivers
- Generates per class and pasenger profit/loss
- Produces a clear profitability and allocation report in the console
